1got — 手機頁內搜尋工具

手機瀏覽器內建的「在頁面上尋找」很難用（找不到、不支援 regex、按鈕太小）。這裡提供兩種解法：①書籤小工具（可在任何網頁上直接用，效果最好）、②貼文字搜尋（給無法加書籤的 App 內建瀏覽器用）。

① 書籤小工具（推薦，可在任何網頁使用）

原理：把一段小程式存成瀏覽器書籤；之後在任何網頁按下這個書籤，就會在該網頁本身跳出搜尋列，直接高亮、支援 regex／整字／大小寫、大按鈕換下一個。這段程式只在你主動點擊時才會執行，不會自動跑、不會回傳任何資料。

iOS Safari
Android Chrome
  1. 先把這個頁面加入書籤：分享圖示 → 「加入書籤」。
  2. 打開 書籤 (Bookmarks) 列表，點 編輯 (Edit)，選到剛加的書籤。
  3. 把書籤的「網址」欄整段清掉，貼上下面文字框裡的完整程式碼，儲存。
  4. 之後去任何想搜尋的網頁，打開書籤列表點它，畫面下方就會跳出搜尋列。
  1. 先把這個頁面加入書籤（網址列旁的星號，或選單「加入書籤」）。
  2. 開啟 Chrome 選單 → 書籤 → 找到剛加的書籤，長按或點右上角三點選「編輯」。
  3. 把「網址」欄清空，貼上下面文字框裡的完整程式碼，儲存。
  4. 之後去任何想搜尋的網頁，開書籤列表點它即可。
